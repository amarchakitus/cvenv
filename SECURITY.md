# Security policy

## Supported versions

Security fixes are made for the latest release only. Update with `cvenv self-update` (or by
re-running the installer for releases before 0.4.0).

## Reporting a vulnerability

Please don't report security issues in public issues or pull requests. Report them privately
through GitHub's
[private vulnerability reporting](https://github.com/amarchakitus/cvenv/security/advisories/new)
instead.

Include what you can of the following:

- the affected version (`cvenv --version`) and backend (Apptainer or squashfuse)
- a description of the issue and its impact, for example on a shared cluster
- steps to reproduce, or a proof of concept

## What to expect

- An acknowledgement within a few days.
- An assessment of the report and, if it is confirmed, a plan for a fix. You will be kept
  informed of progress through the advisory.
- A fixed release, followed by a published security advisory. You will be credited unless you
  prefer otherwise.

Please keep the issue confidential until the fix is released.
